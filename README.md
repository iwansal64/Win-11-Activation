# Win-11-Activation
Shortcut to activate windows 11
<br/>
<br/>

### First Option
This is the fastest option you can use to activate windows 11
1. Run this command in Command Prompt as Administrator:
```
slmgr /ipk TX9XD-98N7V-6WMQ6-BX7FG-H8Q99
slmgr /skms e8.us.to
slmgr /ato
```
2. Done :)


### Second Option
If you can't use the first option (either blocked, or there's an unexpected windows update) use this as fallback
1. Run this command in powershell as Administrator:
```
irm https://get.activated.win | iex
```
2. Choose `HWID Activation` or just press 1
3. Restart Windows 11
